Download

Drag one window onto another. Now they share a tab bar.

GrpTabs puts a small tab above every window on your PC. Drop one tab onto another window and the two become one, with tabs like a browser. It works with any app: Explorer, Notepad, PowerShell, Word, the lot.

Download for Windows

Free for Windows 10 and 11. About 10 MB, no admin rights needed, and it updates itself.

Three moves, nothing to learn

  1. Drag to group

    Grab a window's tab and drop it on another window's tab or title bar. Both windows now share one frame and one tab bar.

  2. Click to switch

    Each window keeps its own tab. Click one and that window comes to the front, in exactly the same place and size.

  3. Drag out to split

    Pull a tab away and drop it on the desktop. That window steps out of the group and lands where you let go.

The rest of it

Keyboard first
Ctrl+Alt+PageDown and PageUp move between tabs, Ctrl+Alt+1 to 9 jump straight to one, Ctrl+Alt+D pulls a window out, Ctrl+Alt+G pauses everything. Change any of them. Or just scroll over the tabs.
Leave some apps alone
Put a program on the exceptions list and its windows never get tabs. Task Manager is there to start with.
Group by itself
Tick a program and its new windows join an open window of the same program, so every Explorer window lands in one stack.
Tabs only when you want them
Show tabs all the time, only when the pointer is over a window, or never. Pick the width, the see-through amount, and light or dark. They step aside when a video or game goes full screen.
A colour for every tab
Out of the box each tab gets its own colour, so you can tell windows apart at a glance. Prefer one colour? Pick from ten, use your Windows accent, or choose any colour. Right-click a single tab to colour just that one.
Switches instantly
Click a tab and that window is simply there, with no Windows open animation and no blink in between. Each tab has its own close button, and right-click gives you the rest.
Never loses a window
Windows waiting behind a tab are written down before they are hidden. Quit, update or even crash, and they all come back.
Keeps itself current
GrpTabs checks for new versions, downloads them quietly and tells you when one is ready. A restart installs it.

Settings you can actually read

One window, six pages, plain switches. Open it from the notification area or the Start menu. Nothing changes until you press Apply or OK.

Why I made it

I'm Erick Omari. Most days I have a ticket open in the browser, two PowerShell windows, Explorer, Notepad and whatever I'm writing, all fighting for the taskbar. I wanted them grouped the way browser tabs are, by the task I'm doing rather than by the app they belong to.

So I built GrpTabs. It's small, it's free, and it stays out of the way until you drag something. If it saves you a few alt-tabs a day, it has done its job. Tell me what you'd change.

Questions people ask

Windows says it protected my PC. Is GrpTabs safe?

The installer isn't code-signed yet, so SmartScreen doesn't recognise it. Choose More info, then Run anyway. The full source is on GitHub if you want to read or build it yourself.

Do I need administrator rights?

No. GrpTabs installs for your account only. Because of that, Windows won't let it move windows of apps you started as administrator, so those simply don't get tabs.

I already use TidyTabs. Can both run?

They can, but both draw tabs in the same spot above each window, so they get in each other's way. GrpTabs tells you when it sees TidyTabs running. Pause or quit one of them.

What happens to hidden windows if I quit?

Every window that was waiting behind a tab is shown again, where the group was. If GrpTabs stops unexpectedly, it puts them back the next time it starts.

How do updates work?

GrpTabs checks GitHub when it starts and every six hours. When a new version is downloaded you get a notification; choose Restart to update, or it installs the next time GrpTabs closes. You can turn this off in Settings, General.

How do I uninstall it?

Settings, Apps, Installed apps, GrpTabs, Uninstall. It removes itself from startup and leaves your windows as they were.
